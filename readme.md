# DSA Practice Repository

This repository contains C++ practice problems focused on **Data Structures and Algorithms (DSA)**. Each problem is organized into folders based on the topic, such as `Array`, `LinkedList`, `Tree`, `Graph`, and `Pattern`. The problems are designed to help you improve your coding skills and understanding of DSA concepts.

## How to Compile and Run (Windows + g++)

From the project root:

```powershell
g++ .\Array\binary_search_2D.cpp -o .\output\Array\binary_search_2D.exe
.\output\Array\binary_search_2D.exe
```

```powershell
g++ .\pattern\hollow_square.cpp -o .\output\pattern\hollow_square.exe
.\output\pattern\hollow_square.exe
```

## Notes

- Each `.cpp` file is intended to be run independently.
- Keep generated executables inside the `output/` folder.
- Add new practice files in the relevant topic folder.
